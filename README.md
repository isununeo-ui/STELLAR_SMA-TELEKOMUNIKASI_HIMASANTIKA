# STELLAR - HIMASANTIKA

## Deskripsi
Website landing page HIMASANTIKA Universitas Muhammadiyah Cirebon dengan tampilan modern, berfokus pada branding organisasi, program kerja, galeri kegiatan, divisi, dan informasi kontak. Desain dibuat agar terlihat profesional, informatif, dan sesuai dengan identitas organisasi mahasiswa Teknik Informatika yang dinamis serta berorientasi pada teknologi.

## Tech Stack
- React JS
- Vite
- CSS Modules / Custom CSS
- React Icons
- React Router DOM

## Instalasi
Ikuti langkah-langkah berikut untuk menjalankan website ini secara lokal:

1. Clone atau masuk ke folder project.
2. Pastikan Node.js sudah terinstal di komputer Anda.
3. Buka terminal pada folder proyek.
4. Jalankan perintah berikut untuk menginstall dependency:

```bash
npm install
```

5. Setelah proses instalasi selesai, jalankan aplikasi:

```bash
npm run dev
```

6. Buka browser dan akses URL yang ditampilkan di terminal, biasanya:

```bash
http://localhost:5173
```

## Build untuk produksi
Untuk membuat versi produksi, jalankan:

```bash
npm run build
```

Lalu untuk preview hasil build:

```bash
npm run preview
```

## Catatan
Proyek ini masih bersifat frontend landing page dan dapat dikembangkan lebih lanjut untuk fitur login, backend, atau CMS sesuai kebutuhan organisasi.
